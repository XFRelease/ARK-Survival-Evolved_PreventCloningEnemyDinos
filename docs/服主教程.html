第一章 · 软件总览

软件总览

「禁止克隆敌对恐龙」是方舟生存进化的服务端插件：玩家在克隆舱里只能克隆本部落的恐龙，克隆敌方或他人部落的恐龙会被自动拦截，防止高属性龙的育种成果被人白拿。装好后自动生效，全部行为通过 config.json 配置。

🛡️

克隆拦截

克隆非本部落恐龙的命令被直接拦截，克隆舱不会启动，龙复制不出来。

🧭

部落精准判定

按部落 ID 比对发起玩家与目标恐龙，同部落照常克隆，互不影响正常玩法。

💬

拦截提示自定义

被拦截的玩家收到屏幕中央提示，文案、显示时长、颜色全部可在配置里改。

📝

拦截留痕

每次拦截记录玩家 SteamID、双方部落 ID、恐龙名、命令名，按天写入日志文件。

♻️

配置热重载

改完配置执行一条 Reload 命令立即生效，不用重启服务器。

📦

轻量部署

单 DLL 插件，不连数据库、不需要额外运行库，放对目录即可用。

第二章 · 环境要求

环境要求

项目要求
操作系统Windows x64（方舟服务端本身的运行环境）
服务端框架已安装 ArkApi 的方舟生存进化服务端，ArkApi 版本不低于 3.5
插件文件PreventCloningEnemyDinos.dll、PluginInfo.json、config.json 三个文件
其他依赖无：不使用数据库，不需要额外运行库
第三章 · 部署安装

部署安装

  1. 找到插件目录

    打开服务器的 ShooterGame\Binaries\Win64\ArkApi\Plugins 目录 → 在里面新建文件夹 PreventCloningEnemyDinos → 下一步。

  2. 放入插件文件

    把 PreventCloningEnemyDinos.dll、PluginInfo.json、config.json 三个文件复制进刚才新建的文件夹 → 下一步。

  3. 启动服务器

    正常启动方舟服务端 → ArkApi 会自动加载插件 → 下一步。

  4. 确认加载成功

    在服务器控制台看到一行「先锋.禁止克隆敌对恐龙(1.0) 先锋方舟服主群:138535385 作者QQ:711919」→ 插件已开始工作。

  5. 验证效果

    用部落 A 的玩家尝试克隆部落 B 的恐龙 → 克隆舱无反应，屏幕出现提示文案 → 拦截生效；再克隆本部落的龙确认正常放行。

服务器运行期间不要直接替换 DLL 文件（文件被占用会失败）。更新插件请先关服，再覆盖文件。
第四章 · 配置详解

配置文件说明

插件的所有配置都在一个 JSON 文件里，位置：

服务器目录\ShooterGame\Binaries\Win64\ArkApi\Plugins\PreventCloningEnemyDinos\config.json

完整配置示例（可直接复制后按需修改）：

{
  "ConsoleEncoding": "auto",
  "禁止克隆": {
    "提示消息": "小伙子,又卡BUG呢？想啥呢?意不意外,你看看卡成了吗?",
    "显示秒数": 15,
    "提示颜色R": 0,
    "提示颜色G": 255,
    "提示颜色B": 255,
    "提示颜色A": 100
  }
}
JSON 里逗号、引号一个都不能少：每个键值对之间用英文逗号分隔，字符串要包在英文双引号里，最后一项后面不带逗号。建议用带 JSON 校验的编辑器（如 VS Code）修改；改前先备份一份。

配置总表

本表列出全部配置键与兜底值，可配合页面搜索定位；详细讲法见后续各节。

配置键所在小节兜底值说明
ConsoleEncoding顶层auto服务器控制台的中文编码模式
提示消息禁止克隆见第七章被拦截玩家看到的屏幕提示文案
显示秒数禁止克隆15提示在屏幕上的停留秒数
提示颜色R禁止克隆0提示颜色红色分量（0~255）
提示颜色G禁止克隆255提示颜色绿色分量（0~255）
提示颜色B禁止克隆255提示颜色蓝色分量（0~255）

整个 禁止克隆 节点都可以不写：缺省时插件用全部默认值照常工作，并在控制台黄字提醒「缺少 禁止克隆 节点」。任何一个配置项类型写错或数值越界，插件都会黄字告警并保留默认值，不会导致加载失败。
第四章 · 配置详解

ConsoleEncoding（控制台编码）

什么意思：控制插件往服务器控制台输出中文时用什么编码。不同版本的 ArkApi 控制台编码不一样（3.54 是 GBK，3.55 是 UTF-8），配错了控制台中文会显示乱码。这个配置只影响控制台显示，不影响拦截功能本身。

兜底值：auto（不配置或值非法时自动探测：按控制台当前代码页决定转不转码）

怎么修改：可选值如下表；值大小写不限；写成其他内容会黄字告警并回落 auto。

取值效果
auto自动探测（推荐，两种服务器通用）
gbk 或 ansi强制按 GBK 输出（ArkApi 3.54 的服务器）
utf8 或 utf-8强制按 UTF-8 输出（ArkApi 3.55 的服务器）

只接受字符串类型：写成数字等其他类型按非法值处理，黄字告警后回落 auto。

第四章 · 配置详解

提示消息

什么意思：玩家尝试克隆非本部落恐龙被拦截时，屏幕中央弹出的提示文字。想换成正经警告或换成你服务器的风格，改这里。

兜底值：小伙子,又卡BUG呢？想啥呢?意不意外,你看看卡成了吗?

{
  "禁止克隆": {
    "提示消息": "克隆失败：只能克隆本部落的恐龙！"
  }
}

怎么修改：把引号里的文字换成你想要的提示即可，中文英文都行。必须是字符串（带双引号）；写成数字等类型会黄字告警并保留默认文案。修改后执行 Reload 命令立即生效。

第四章 · 配置详解

显示秒数

什么意思：提示消息在玩家屏幕上的停留时间（秒）。时间到后提示自动消失。

兜底值：15 秒

{
  "禁止克隆": {
    "显示秒数": 8
  }
}

怎么修改：填数字，合法范围是大于 0 且不超过 3600；越界或类型不对会黄字告警并保留默认 15 秒。示例改成 8 表示提示停留 8 秒。

第四章 · 配置详解

提示颜色RGBA

什么意思：提示文字的颜色。R/G/B 是红绿蓝三色分量，A 是不透明度，各填 0~255 的数字。默认 0,255,255,100 是半透明青色。

兜底值：R=0 G=255 B=255 A=100

{
  "禁止克隆": {
    "提示颜色R": 255,
    "提示颜色G": 200,
    "提示颜色B": 0,
    "提示颜色A": 255
  }
}

怎么修改：四个键必须同时存在且都合法才会生效：任何一个缺失、类型不是数字、或数值超出 0~255，整组颜色保留默认值并黄字告警。示例改完是醒目的不透明橙黄色。

第五章 · 命令用法详解

命令总表与 Reload

本插件只有一条管理命令，在服务器控制台或 RCON 远程管理工具里输入，玩家在游戏内聊天框用不了，也没有玩家命令。命令名不支持通过配置改名。

命令权限作用改名配置键
PreventCloningEnemyDinos.Reload控制台·RCON重新读取 config.json，配置立即生效不支持改名
符号约定：命令格式里的 [方括号] 表示可选参数，只是标注——实际输入时不要输入方括号。本插件的命令无任何参数，照抄整条命令即可。

PreventCloningEnemyDinos.Reload

作用：修改 config.json 后不重启服务器，直接让新配置生效（提示文案、颜色、编码等全部重新读取）。

PreventCloningEnemyDinos.Reload
参数必填缺省值说明
（无）——本命令无参数

示例：PreventCloningEnemyDinos.Reload（整条照抄：服务器立即重新读取配置文件并应用）。

反馈：配置读取成功，控制台回绿字 Reloaded config（RCON 端同样收到这条文本）；config.json 不存在或 JSON 格式坏了，控制台回红字 Failed to reload config（RCON 收到具体错误原因），此时继续沿用旧配置，不影响拦截功能运行。

第六章 · 常见问题

常见问题

玩家说克隆别人家的龙“没反应”？
这就是插件的正常工作状态：非本部落恐龙的克隆命令被拦截，克隆舱不会启动。玩家屏幕中央应同时出现提示文案；如果没注意看，提示默认停留 15 秒。可在 日志\日期.txt 里查到这条拦截记录。
改了 config.json 但没生效？
先执行 PreventCloningEnemyDinos.Reload 命令热重载；控制台回绿字 Reloaded config 才算生效。若回红字 Failed to reload config，说明 JSON 格式有错（多半是少了逗号或引号），对照第四章的完整示例检查。
找不到 config.json 在哪？
固定路径：服务器目录\ShooterGame\Binaries\Win64\ArkApi\Plugins\PreventCloningEnemyDinos\config.json。第一次部署时随插件一起放进去。注意：这个文件必须存在——被删掉或读不到时插件会加载失败（控制台报 Can't open config.json），把文件恢复后重启服务器即可；只是少写某个配置项则没关系，会按默认值运行。
配置值写错了会怎么样？
不会崩服也不会加载失败：类型不对或数值越界的配置项会被忽略并保留默认值，同时控制台黄字提示是哪个键非法。对照黄字提示改回来再 Reload 即可。
怎么查谁尝试克隆别人的龙？
看日志文件：服务器运行目录下的 日志\日期.txt（按天一个文件，UTF-8 编码），每条拦截记录包含玩家 SteamID、玩家部落、恐龙部落、恐龙名、命令名。
本部落互相克隆会被误拦吗？
不会。判定标准是发起玩家与目标恐龙的部落 ID 一致即放行；只有克隆其他部落的龙才拦截。同部落的队友、自己的龙都正常克隆。
控制台中文显示乱码？
把 config.json 里的 ConsoleEncoding 调成与服务器 ArkApi 版本匹配的值：3.54 的服务器填 gbk，3.55 填 utf8；不确定就保持 auto 自动探测，然后 Reload。乱码只影响控制台显示，不影响任何功能。
控制台黄字提示「未找到 APrimalDinoCharacter 类」？
这是插件在服务器对象列表里没找到恐龙类的告警，出现期间克隆命令会全部放行（不拦截），插件每次处理克隆命令时都会自动重试，找到类后拦截自动恢复，告警只出现一次。正常情况不会出现；若持续出现导致拦截一直不生效，把服务器和 ArkApi 版本信息反馈给作者排查。
